# Quick Prompt — 模块化内容体验生成

请使用 **Micas Doc-to-Interactive-Training Skill v3**。

模块选择：

```text
品牌：[micas / 其他品牌包路径]
模式：[interactive-training / gamified-learning / executive-report / marketing-content]
```

默认使用：

```text
品牌：micas
模式：interactive-training
```

请按顺序读取：

1. `modules/CORE.md`
2. 选中的`modules/modes/`模式文件
3. 选中的`modules/brands/`品牌文件
4. `modules/UI.md`
5. `modules/QA.md`

然后把我上传的源资料直接生成完整成品。

项目设置：

- 标题：[填写或自动生成]
- 受众：[填写]
- 目标：[填写]
- 时长/篇幅：[填写]
- 默认语言：English
- 其他语言：[English / 简体中文 / 繁體中文 / 日本語]
- 特殊要求：[填写]

强制要求：

- 完整读取正文、表格、图片、警告、步骤和附录。
- 以源资料为事实依据，不编造技术、性能、合规、客户或市场信息。
- 按选中的模式组织结构和互动。
- 按选中的品牌包使用Logo、色调、品牌语气和参考素材。
- 不把品牌逻辑、模式逻辑和通用UI规则混在一起。
- 直接生成完整可下载成品，不只给方案或样章。
- 交付前执行`modules/QA.md`全部适用检查并修复严重缺陷。

默认Micas互动培训模式还必须保持：深蓝背景、一页一屏、完整大图、大正文、课程分模块、Google语音默认、完整旁白后翻页、考试集中在最后模块、考试题不自动播放、全文搜索和离线单文件HTML。
