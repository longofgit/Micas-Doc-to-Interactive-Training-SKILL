# UI Reference Assets

These files are supplemental visual guidance for the **Micas Doc-to-Interactive-Training Skill**. Written specifications remain authoritative.

## Header Lockup

### `header-lockup-reference.svg`

Approved upper-left header composition:

- large transparent Micas logo on the left;
- course title and product/module subtitle stacked to its right;
- strong white title and softer muted subtitle;
- vertically centered horizontal lockup;
- deep-navy background with a restrained cyan divider;
- no card, white box, or cramped utility buttons around the lockup.

See `HEADER_UI_SPEC.md`.

## Main-Content References

### `content-hero-product-split-reference.svg`

Use for orientation, product introduction, and mission-opening scenes:

- oversized selective headline;
- readable supporting paragraph;
- three short outcome cards;
- large complete product visual in a controlled light frame;
- balanced 50/50 or 55/45 composition.

### `content-checkpoint-positioning-reference.svg`

Use for product positioning or concept checkpoints:

- clear checkpoint eyebrow;
- one memorable positioning statement;
- three substantial supporting cards;
- complete product image with concise feature chips.

### `content-checkpoint-redundancy-airflow-reference.svg`

Use for hardware-memory, redundancy, cooling, or component-recognition scenes:

- large technical headline;
- three strong facts with memorable icons/numbers;
- warning text emphasized selectively;
- large complete rear-panel or component image.

### `content-key-metrics-power-reference.svg`

Use when a small set of numbers matters operationally:

- full-width title and eyebrow;
- four oversized metric cards;
- short labels rather than dense specification tables;
- one supporting explanation band for voltage, limits, or operational meaning.

## Header Utility Controls

### `header-action-icons-reference.svg`

Use for the upper-right controls:

- language/globe/translation icon plus current language;
- video-camera or play icon plus Auto Play/Video label;
- fullscreen-corners icon plus Fullscreen label;
- consistent alignment, stroke weight, spacing, and button treatment.

## Usage Rules

- Inspect the relevant reference before creating the corresponding scene or control.
- Recreate the design language using live HTML/CSS, localizable text, and authentic source-document visuals.
- Do not use these references as flattened production pages.
- Do not copy example technical facts into unrelated courses.
- Preserve the established Micas palette, typography hierarchy, spacing, and complete-image behavior.
- When image inspection is unavailable, follow `COURSE_EXPERIENCE_SPEC.md`, `HEADER_UI_SPEC.md`, and `UI_DESIGN_SPEC.md` as the authoritative fallback.
