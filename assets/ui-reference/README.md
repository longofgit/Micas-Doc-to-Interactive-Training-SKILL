# UI Reference Assets

## Header Lockup Reference

`header-lockup-reference.svg` is the approved visual reference for the upper-left course header lockup.

Use it as a composition reference, not as a literal screenshot to embed in generated courses. The generated header must reproduce the design language with live HTML/CSS:

- large transparent Micas logo on the left;
- course title and product/module subtitle stacked to its right;
- strong white title and softer muted subtitle;
- vertically centered single-row lockup;
- deep-navy background with a restrained cyan divider;
- no card, white box, or cramped utility buttons around the lockup.

The written rules in `SKILL.md` and `UI_DESIGN_SPEC.md` remain authoritative. This image is supplemental visual guidance so agents can inspect the intended proportions and spacing.
