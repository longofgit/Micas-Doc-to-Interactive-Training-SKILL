# Experience Mode: Executive Report

Version: **3.0.0 starter profile**

Mode ID: `executive-report`

This optional mode is inactive unless explicitly selected.

# Purpose

Convert source material into a concise, evidence-grounded management report or presentation focused on decisions, progress, risks, outcomes, and next actions.

# Architecture

Recommended structure:

1. Executive summary
2. Context and objective
3. Current state
4. Key findings or achievements
5. Evidence and metrics
6. Risks, gaps, and constraints
7. Options or recommendations
8. Decisions required
9. Action plan, owners, and timeline
10. Appendix or source references

# Presentation Model

- Use presentation-style pages or a paged report.
- Prioritize conclusions, evidence, and decisions over instructional narration.
- Use charts, metrics, timelines, decision matrices, and concise evidence blocks when supported by the source.
- Avoid quizzes, scores, badges, and learner language unless explicitly requested.
- Search, appendix, and source traceability may remain available.

# Claims and Metrics

- Every metric and conclusion must map to the source.
- Separate facts, analysis, assumptions, and recommendations.
- Do not convert an assumption into an achieved result.
- Clearly mark data gaps and unresolved risks.

# Narration

Narration and Auto Play are optional. When enabled, they follow the selected UI and completion rules, but no assessment behavior is required by default.

# Deliverables

1. executive presentation or interactive report;
2. evidence/source map;
3. decision and action register when applicable;
4. QA Report;
5. README.

# Mode QA

Release blockers include:

- unsupported claims or metrics;
- unclear distinction between fact and recommendation;
- missing decisions or next actions when the source supports them;
- unreadable charts;
- excessive technical detail in the main executive flow;
- generic filler replacing source evidence.
