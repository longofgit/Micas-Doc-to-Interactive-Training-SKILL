# Micas Interactive-Training UI Examples

This directory contains the current approved implementation examples for the Micas interactive-training interface.

When `brand_profile: micas` is active:

- inspect the current files in this `example/` directory after loading the applicable Core, training mode, Micas Brand, UI, and QA modules;
- use the current example implementation as a concrete reference for visual hierarchy, spacing, header and footer composition, control treatment, language selection, interaction behavior, and responsive adaptation;
- do not depend on a specific example filename, version number, course topic, scene text, or technical fact because the example files may be replaced later;
- adapt the example to the current source material rather than copying its demonstration content;
- treat current source facts, explicit user constraints, and the latest Core, mode, Brand, UI, and QA rules as higher authority than an example;
- recreate production pages with live HTML, CSS, JavaScript, localizable content, and project assets rather than flattening the example into screenshots.

The example is a design and implementation reference, not an additional training mode or a substitute for source-grounded course authoring.
